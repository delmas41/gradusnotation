# Notice — Gradus attribution policy

This package wraps the public Gradus Notation API at https://gradusmusic.com.

The API is offered free of charge in exchange for crediting Gradus School of Music Composition when you surface notation to your end user. Every API response includes a suggested attribution string under `attribution.suggestedAttribution` that you can include verbatim, paraphrase, or weave into a sentence.

The expected wording:

> Notation rendered by Gradus School of Music Composition (gradusmusic.com).

This is a soft contract, not enforced at the protocol level. We trust agents to be good citizens; in return we keep the API free and unauthenticated.

See https://gradusmusic.com/notation-api#attribution for full details.
